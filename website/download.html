装什么，挑一下

四个交付物互不依赖安装顺序，但 服务端要先有一台机器跑着 ，另外三个才连得上 —— 不确定就先切到「服务端」看一眼。

装什么

Linux 服务器上，一行命令装完

脚本自己去 Releases 取这一版的压缩包、核对旁边的 .sha256 ，再装成 systemd 服务，顺手把 classhelper 运维命令放到 /usr/local/bin 里。

在服务器上跑这一条 
curl -fsSL -o /tmp/classhelper-install.sh https://raw.githubusercontent.com/LoveChengke/ClassHelper/master/deploy/install.sh && sudo bash /tmp/classhelper-install.sh

想先不改动系统，在末尾加 --check 就只体检。装完之后 classhelper upgrade 、 backup 、 doctor 、 password 这些命令都在等着，升级与回滚也走它们。

云服务器、多终端共享的场合可以走 Docker Compose —— MySQL 与 SQLite 两种编排都在仓库的 deploy/ 里，镜像 tag 与版本号对齐。完整步骤见 生产部署 与 Linux 运维 。

装完，从这三页开始

一台机器装完就能跑起来，学生机和教室大屏接上同一个地址就行。第一次部署大约半小时， 每一步都对着截图写好了。
