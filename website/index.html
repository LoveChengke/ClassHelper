它是怎么工作的

从按下「发布」到教室屏幕上弹出来

中间只隔着一条 WebSocket 广播。实测从老师提交到教室机器收到，是 30 到 50 毫秒 —— 这个数字由 pnpm verify:e2e 每次跑的时候重新量，不是写在文档里的估计值。

  1. 老师发布

    Web 管理端或手机浏览器。通知、作业、叫人、成绩都在这里录。

  2. 后端落库

    Express 5 + Prisma 7 写进库，再按班级房间广播一条事件。

  3. 教室收到

    Socket.IO 推到 class:班级 房间 —— 教室机器、学生机、大屏同时收到。

  4. 判一次时间

    课表服务回答「现在上不上课」，当场弹还是先收着，这一步就定下来了。

  5. 两端弹出

    灵动岛展开成卡片，ClassIsland 同时全屏提醒，可以语音朗读。

它是怎么构成的

一份代码，四个交付物

一个 pnpm monorepo。三端共用同一份类型与权限矩阵，所以不会出现「Web 端说有、客户端说没有」。

四个交付物、它们的形态与使用者
交付物 形态 谁在用
后端服务 Express 5 + Prisma 7 + Socket.IO，接口前缀 /api 其它三端
Web 管理端 Vue 3 + Element Plus，手机可用，可在浏览器里装成应用 老师、管理员
桌面客户端 Electron + Vue 3，带灵动岛与系统托盘，断网可用 教室机器、学生机
ClassIsland 联动插件 .NET 8 插件，装进教室已有的 ClassIsland 里 教室大屏

它是怎么到你手里的

四种装法，按场景挑

四种部署形态与各自入口
场景 形态 入口
教师电脑、学校机房单机 Windows 服务端安装程序，内置 Node 运行时 双击安装，自动建库建号、开机自启
云服务器、多终端共享 Docker Compose，MySQL 与 SQLite 两种编排都在仓库里 deploy/docker-compose.yml
已有 Linux 服务器 一行命令装成 systemd 服务，附带 classhelper 运维命令 见下面的命令
已有 Node 环境 免安装目录，自带 node.exe pnpm dist:server 的产物
Linux 服务器上跑这一条 
curl -fsSL -o /tmp/classhelper-install.sh https://raw.githubusercontent.com/LoveChengke/ClassHelper/master/deploy/install.sh && sudo bash /tmp/classhelper-install.sh

脚本自己从 GitHub Release 取最新版、核对发布页上的 .sha256 ，再装成 systemd 服务。 想先不改动系统，把末尾换成 --check 就只体检。装完之后， classhelper upgrade 、 backup 、 doctor 、 password 这些命令都在 /usr/local/bin 里等着。

学生机这边是安装包和单文件版两种：安装包走 NSIS，单文件版不用装、放 U 盘里就能分发。 两个都不写死服务器地址 —— 第一次打开时填教室的地址和班级码就行。
