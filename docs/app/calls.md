# 叫人

在 Web“通知发布 → 叫人”选学生，填写事由或选择快捷短语，需 call:create 和班级范围权限。
可调用的学生必须属于相应在读班级且未转出；岗位范围、任课或班主任关系由服务端检查。
学生没有账号，无法以个人身份调用接口。

| 级别     | 落库优先级 | 经典 fixed 展示                                                    |
| -------- | ---------- | ------------------------------------------------------------------ |
| 普通叫人 | HIGH       | 胶囊可点击，上课也允许主动查看；不自动展开打断课堂，下课可自动展开 |
| 紧急叫人 | URGENT     | 上课也立即展开，收起后仍可主动再打开                               |

自定义 custom 是常驻模式，两种叫人都先提示铃铛，由用户主动查看；详见[通知与提醒](notifications.md)。
卡片内容包括被叫学生、教师和事由，“收到”复用通知已读机制。
自定义消息优先于快捷短语，消息长度以接口 schema 校验为准。

`POST /api/calls` 保存为 Notification，带本地所属日期；随后发送 notification:new 班级广播和 call:new 班级会话定向事件。
定向主体是班级会话，学生本身没有 Socket 房间；双播按消息 id 合并去重。
