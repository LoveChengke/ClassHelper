# 班级、学生与教师

## 班级账号：学生端的身份

学生**没有个人账号**。一台教室机器用一个**班级账号**登录：

```
班级码（例如 G203） + 班级密码  →  这台机器代表"高二(3)班"
```

登录之后，这台机器上的「已读 / 完成 / 未交」都是**代全班**操作的；它看到的是本班的数据。

班级码是管理员在「班级管理」里设的（新建时自动生成，可以改成好记的）。
校验时会统一按大写比对（码存大写）。

> 班级密码在新建班级时由 `.env` 的 `DEFAULT_CLASS_PASSWORD` 决定初始值，
> 之后由管理员在「班级管理 → 修改班级账号」维护。
>
> **客户端没有改密码入口**，这是刻意移除的：教室机器上误改班级密码会让别的机器登录不了。
> 教师 / 管理员本人改密码在 Web 端顶栏头像菜单里。

## 学生

**学生管理**（仅管理员）→ 新建 / 导入名单。

学生记录**只是名单**：成绩、未交名单、叫人、已读记录都按名单记录，所以名单不全这几项就不准。

| 项目     | 说明                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 用户名   | `^[A-Za-z0-9_.-]{3,32}$`；单个新建时自动生成                                         |
| 密码     | **没有密码概念**。学生的 `passwordHash` 是空串占位，不能登录，也没有任何重置密码接口 |
| 所属班级 | 一个学生属于一个主班级                                                               |

> 用学生用户名去登录会被拒。就算拿教师 / 管理员账号去试，服务端也会在**密码校验之前**先判角色 ——
> 否则"密码错(401)"和"密码对但学生账号已停用(403)"的差异会把学生账号密码变成可离线验证的预言机。

## 教师

| 能力                 | 在哪                                             | 谁能做        |
| -------------------- | ------------------------------------------------ | ------------- |
| 新建 / 编辑 / 删除   | 「教师管理」                                     | **仅管理员**  |
| 导入名单（xlsx/csv） | 「教师管理 → 导入名单」                          | **仅管理员**  |
| 重置密码             | 「教师管理」（可指定新密码，留空用默认初始密码） | **仅管理员**  |
| 加进某个班           | 班级详情 → 协作教师                              | 管理员 / 教师 |
| 换班主任             | 班级详情顶部「更换班主任」                       | **仅管理员**  |

> **教师录入只有管理员能做**：`/api/teachers` 整组接口都是 `requireRole('ADMIN')`，教师调用返回 403。
> 前端也只在管理员登录时显示这个菜单项。

### 删除教师有护栏

下面四种情况一律拒绝（409），因为删账号会级联删掉他在各班发过的内容：

1. 他还是某个班的**班主任**；
2. 名下有**课程**；
3. 有**班级分配**（协作教师）；
4. **发布过作业或通知**。

（后两项曾经漏检，会静默删掉该教师发过的作业与通知。）

## 角色与可见范围

班级内的角色由「账号角色 + 与该班级的关系」共同决定：

| 角色               | 怎么判定                       | 可见范围                   |
| ------------------ | ------------------------------ | -------------------------- |
| `ADMIN` 管理员     | `User.role = ADMIN`            | 全部班级                   |
| 班主任 `HEAD`      | `Class.teacherId === 当前用户` | 本班                       |
| 科任老师 `SUBJECT` | `ClassTeacher` 里有当前用户    | 被分配的班级               |
| 学生 `STUDENT`     | `User.classId` / 班级账号      | 自己的班级（只读业务数据） |

### 权限矩阵（摘要）

| 操作                                 | 管理员 |    班主任    | 科任老师 |
| ------------------------------------ | :----: | :----------: | :------: |
| 班级创建 / 修改 / 删除               |   ✅   |      ❌      |    ❌    |
| 分配班主任与科任老师                 |   ✅   |      ❌      |    ❌    |
| 学生名单管理（增删 / 导入）          |   ✅   |      ❌      |    ❌    |
| 教师录入（新建 / 导入 / 改密码）     |   ✅   |      ❌      |    ❌    |
| 数据库管理（备份 / 导入导出 / 切换） |   ✅   |      ❌      |    ❌    |
| 课表管理（增删改 / 导入）            |   ✅   | ✅（仅本班） |    ❌    |
| 布置作业                             |   ✅   |      ✅      |    ✅    |
| 叫人                                 |   ✅   |      ✅      |    ✅    |
| 发布通知                             |   ✅   |      ✅      |    ✅    |
| 成绩录入 / 修改 / 导入（仅本班）     |   ✅   | ✅（仅本班） |    ❌    |
| 维护班级密码                         |   ✅   |      ❌      |    ❌    |

完整矩阵与实现见[角色与权限](../dev/permissions.md)。

## 学期周数

每个班有自己的学期周数（`Class.termWeeks`，默认 20，上限 30），**只有管理员**能改。
它决定"现在是第几教学周"，见[课表](schedules.md)。
