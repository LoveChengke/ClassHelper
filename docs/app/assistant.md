# AI 助手

在 Web 管理端描述任务、补充条件或添加文件，助手会查询所需信息并生成操作计划。查询直接显示结果；任何发布、修改、导入和设备操作，都要核对计划并确认后执行。

## 使用

1. 可先选择目标班级，再输入任务；文件也可以直接拖入对话区。
2. 信息不足时补充说明。核对目标、文件、修改前内容和本次变更；表格导入可调整字段对应。
3. 确认执行后逐步显示结果。跨班发布按班显示进度，成功班级不会重复执行。失败时只重试尚未成功的步骤；结果不明时先在对应业务页面核对。

文件推送复用课件上传、哈希校验和设备回执，普通课件上限 512 MB。结构化导入支持现有 CSV、Excel、JSON、YAML 格式，上限 8 MB，先解析预览，确认后才写入业务数据。

## 权限

助手权限跟随操作者。教学业务、课表时间表、名单成绩、账号岗位和设备操作均使用原业务接口的授权规则；管理员专用功能仍限管理员。确认期间撤权、调班或任课关系变化后会重新校验。

数据库备份、恢复、清空、切换、SQL，以及服务器配置、启停、升级和密钥维护不向助手开放。删除、权限调整、升学和远控保留专门确认；上课时的紧急通知仍需二次确认。

管理员可让助手抓取、登记或删除客户端安装包缓存，核对版本、文件与替换信息并专门确认后执行。缓存管理不会自动推送、运行安装器或升级服务器。助手也可按设备权限处理远控、更新推送和移除设备登记。

密码通过操作卡片中的专用表单输入，不提供给模型。用户指令与任务所需的已授权业务信息由学校配置的模型服务解析；普通课件只提供文件元数据。

任务提交后在服务端后台运行，切换页面或关闭浏览器不取消规划及已确认的执行。重新进入助手可恢复最近任务、处理过程和结果；未确认的变更始终等待确认。停止按钮才会主动停止任务；已经发出的当前业务请求可能完成，后续步骤停止。服务重启后保留任务及步骤状态，核对后继续，未知执行结果不会自动重做。

附件须先上传完整并通过 SHA256 校验，之后才进入后台。关闭页面会中断尚未完成的本地上传，此时重新选择原文件；暂存不发布课件。临时附件在完成后清理，过期一天的暂存会在创建新任务时回收。后台输入、结果和进度加密保存；恢复查询时重新检查当前权限。计划与执行结果记入服务端审计。

处理过程实时显示权限检查、查询、自动校正、预览和执行阶段。空白或截断回复自动重试，兼容 JSON 代码块包装；业务参数仍须通过原接口校验。若模型持续不可用，任务保留为未完成并提供重试，不伪报成功或自动执行未确认操作。

## 模型配置与验收

管理员在大模型设置中配置服务地址、模型和 API Key。Key 加密保存且不回传；改变服务器 JWT 密钥后需重新配置 Key。

服务地址既可填写基础地址（如 `https://api.deepseek.com`、`https://api.openai.com/v1`），也可填写完整 `/chat/completions` 端点，系统不会重复拼接路径。DeepSeek 例如填写 `https://api.deepseek.com/chat/completions`，模型名须使用该服务实际支持的模型。

填好地址和密钥后自动获取可用模型，也可点击“获取模型”刷新或手动填写。推理强度支持自动及模型提供的档位；服务未提供能力信息时使用通用档位，自动不附加推理参数。模型列表和强度遵循[服务商接口](https://api-docs.deepseek.com/api/list-models/)，不会把密钥返回浏览器。

`mock` 用于离线示例和自动化验收，真实服务失败不会自动切换为 mock 或发布内容。`pnpm verify:ai` 使用临时数据库和模型 stub 验证权限、计划、附件和重复提交，不访问外网。

## 对话与轮次

对话历史按账号保存在服务器。每次发送是一轮，右侧横条可跳转轮次，新对话独立保存。助手缺少必要信息时会弹出提问窗口，可选答案或自由回答。关闭窗口后可通过历史消息中的“回答问题”再次打开，刷新页面也能恢复待回答的问题；追问阶段不执行写入。格式自动修正每轮至多一次，失败后保留明确的重试入口。

勾选“本轮明确替换当前待确认计划”后，新计划形成时只使选中的旧计划失效，历史记录保留。不勾选时保留旧计划；新建对话不影响其他对话的计划。

删除课表等危险操作时，目标明确后会先生成变更预览，点击“确认执行”才弹出危险操作确认窗口。聊天中的“确认”回答只用于继续生成预览，不代替最终执行确认。

在对话历史中选择对话后，可点击“删除对话”。确认后清除该对话的轮次和暂存附件，未完成计划失效；已执行的业务操作及审计记录保留。仍有后台任务时，请先停止或等待完成再删除。
