# AI 助手

AI 助手位于 Web 管理端工作台。输入要发布的作业、通知或叫人请求，助手会展示解析出的班级、科目、内容与提醒级别；核对并确认后才发布。内容仍通过原有业务接口，继续校验当前账号的功能权限、班级范围及任课关系。

## 配置与使用

管理员在大模型设置中开启助手，选择服务地址和模型并保存 API Key。密钥加密存储，读取设置只返回是否已配置及末尾提示，不返回完整密钥。修改服务端 JWT 密钥后，原有加密 Key 需要重新配置。

1. 在助手页面描述操作与目标班级，等待解析预览。
2. 核对班级、科目、标题、正文和提醒级别；有歧义时修改后重新解析。
3. 点击确认发布。紧急通知在上课期间仍需完成额外确认；批量操作逐班返回结果。

解析成功不代表已经发布，也不代表拥有对应班级或科目的写权限。缺少任课关系时，请由管理员配置；助手不能替用户建立授权。

## 离线示例与审计

`mock` 提供确定性的离线示例解析，用于自动化验收，不访问外网；预览会提示当前为示例结果。真实模型调用失败时页面保留可操作的错误说明，不会自动改用发布接口。

有管理权限的账号可查看助手审计。审计记录解析意图和状态，不代替作业、通知或叫人的最终发布结果；请结合对应业务页面核对。
