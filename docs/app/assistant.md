# AI 助手

在 Web 管理端描述任务、补充条件或添加文件，助手会查询所需信息并生成操作计划。查询直接显示结果；任何发布、修改、导入和设备操作，都要核对计划并确认后执行。

## 使用

1. 可先选择目标班级，再输入任务；文件也可以直接拖入对话区。
2. 信息不足时补充说明。核对目标、文件、修改前内容和本次变更；表格导入可调整字段对应。
3. 确认执行后逐步显示结果。跨班发布按班显示进度，成功班级不会重复执行。失败时只重试尚未成功的步骤；结果不明时先在对应业务页面核对。

文件推送复用课件上传、哈希校验和设备回执，普通课件上限 512 MB。结构化导入支持现有 CSV、Excel、JSON、YAML 格式，上限 8 MB，先解析预览，确认后才写入业务数据。

## 权限

助手权限跟随操作者。教学业务、课表时间表、名单成绩、账号岗位和设备操作均使用原业务接口的授权规则；管理员专用功能仍限管理员。确认期间撤权、调班或任课关系变化后会重新校验。

数据库备份、恢复、清空、切换、SQL，以及服务器配置、启停、升级和密钥维护不向助手开放。删除、权限调整、升学和远控保留专门确认；上课时的紧急通知仍需二次确认。

管理员可让助手抓取、登记或删除客户端安装包缓存，核对版本、文件与替换信息并专门确认后执行。缓存管理不会自动推送、运行安装器或升级服务器。助手也可按设备权限处理远控、更新推送和移除设备登记。

密码通过操作卡片中的专用表单输入，不提供给模型。用户指令与任务所需的已授权业务信息由学校配置的模型服务解析；普通课件只提供文件元数据。对话历史保留在当前页面会话，计划与执行结果记入服务端审计。

## 模型配置与验收

管理员在大模型设置中配置服务地址、模型和 API Key。Key 加密保存且不回传；改变服务器 JWT 密钥后需重新配置 Key。

`mock` 用于离线示例和自动化验收，真实服务失败不会自动切换为 mock 或发布内容。`pnpm verify:ai` 使用临时数据库和模型 stub 验证权限、计划、附件和重复提交，不访问外网。
