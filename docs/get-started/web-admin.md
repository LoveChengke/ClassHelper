# 认识 Web 管理端

服务端启动后，用浏览器打开 http://<服务器地址>:4000/，教师或管理员以工号和密码登录。
学生无个人账号，教室客户端使用[班级登录](client.md)。新安装按部署配置创建初始管理员，首次使用后修改初始密码。

## 菜单与权限

侧栏按以下分组组织，具体页面由路由权限筛选，并支持浅色/深色和关怀模式。

| 分组       | 主要页面                                           |
| ---------- | -------------------------------------------------- |
| 工作台     | 仪表盘、AI 助手                                    |
| 教学事务   | 课表、时间表与日课表编辑、作业、通知、课件、成绩   |
| 班级与人员 | 班级、学生、教师、只读学生名单、学期周次、毕业归档 |
| 设备运维   | 客户端在线状态、命令、更新与安装策略               |
| 系统管理   | 权限组、系统设置、大模型设置、数据库管理           |

班级/学生/教师管理、学期周次、归档和数据库页面还有管理员角色门槛；
教师只读名单、教学页与设备页按权限键和数据范围开放。
每次操作服务端继续校验，不是显示菜单就能改所有班和科目。详见[角色与权限](../dev/permissions.md)。
顶栏提供本人密码、使用引导、检查更新与退出等入口。

## 引导与手机

首次登录展示使用引导，完成/跳过后记住；可从顶栏“使用引导”重看。
小屏侧栏收进抽屉，表格在卡片内横向滚动；支持安装 PWA，需要 HTTPS 或 localhost 安全上下文。
同局域网手机填写服务器局域网地址，不用 localhost；公网反代见[生产部署](../management/production.md)。
