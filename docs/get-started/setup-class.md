# 建班级、排课表

后面所有功能（发通知、布置作业、录成绩、接 ClassIsland）都挂在**班级**上，所以先把班级建出来。

## 1. 建班级（仅管理员）

Web 管理端 → **班级管理** → 「新建班级」：

| 字段     | 说明                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 班级名称 | 例如「高二(3)班」                                                       |
| 年级     | 用于分组与统计                                                          |
| 班主任   | 从教师账号里选，默认是自己；之后随时可在班级详情顶部「更换班主任」改    |
| 学期周数 | 默认 20，**上限 30**。课表的周次选择与周次范围都以它为准                |
| 班级码   | 保存时自动生成（字母数字 4–16 位，存大写），可以改成好记的，例如 `G203` |
| 班级密码 | 新建班级时的初始密码就是它 —— 学生在教室机器上要用这个登录              |

> **班级码 + 班级密码 = 学生端的登录凭据。** 学生端没有个人账号，一台教室机器用班级账号登录后，
> 那台机器上的「已读 / 完成」是**代全班**操作的。
>
> 学期周数只有管理员能改：它决定"现在是第几教学周"，乱改会让课表的周次过滤和上课时段判定错位。

## 2. 加学生（仅管理员）

**学生管理** → 「新建」或「导入名单」：

- **单个新建**：填姓名即可，登录名会自动生成。
- **导入名单**：下载模板（列只有 `用户名 / 姓名`，学生没有账号属性，**没有密码列**），填好上传。
  用户名要匹配 `^[A-Za-z0-9_.-]{3,32}$`；重复用户名在 `append` 模式下跳过、`upsert` 模式下更新姓名。
  用户名已经属于某个教师 / 管理员账号时，这一行会进错误列表，不会覆盖别人的账号。

学生的用途是：**成绩、未交名单、叫人、已读记录都按名单记录**。所以名单不全，这几项就不准。

## 3. 加科任老师

教师的**录入**只有管理员能做（**教师管理**页，支持单个录入与导入名单）。班级层面的**分配**在班级详情里：
把老师加进「协作教师」，他就能看到这个班、给这个班发作业 / 通知 / 叫人。

角色与可见范围见[班级、学生与教师](../app/classes.md)与[角色与权限](../dev/permissions.md)。

## 4. 排课表

**课表管理** → 选中班级 → 「新增课表」：

- **科目**下拉直接列出全校统一的 18 科目录（语文 / 数学 / 英语 / 政治 / 历史 / 物理 / 化学 / 地理 /
  生物 / 信息技术 / 体育 / 美术 / 音乐 / 班会 / 早读 / 晚读 / 通用技术 / 听力）。
  选中一个该班还没有的科目时，前端会**自动为该班建同名课程**，不用先去把科目的建一遍。
- 填星期、开始 / 结束时间、周次范围（第几周到第几周）、单双周（每周 / 单周 / 双周）。
- 一节课**必须同时有开始时间和结束时间** —— 「上课时段」的判定就是拿这两个时间比对的。

排完在**课表管理**里能看到周视图（7 列），客户端那边则多一个「今天」时间轴视图。

### 从 ClassIsland 导入更省事

如果教室里已经在用 ClassIsland，直接导入它的档案 JSON 就行：课表、节次时间、单双周都会一起进来，
不用排两遍。见[表格与课表导入](../app/imports.md)。

## 5. 确认「上课时段」判定是对的

班级小助手有一整套「上课时段策略」：普通通知在上课时段只进队列、下课自动补弹，紧急通知与叫人则立刻弹。
这套判定完全基于课表，所以**课表排错，提醒就会在该弹的时候不弹**。

排完课之后建议立刻验一下：在**通知发布**页选这个班，随便发一条普通通知，
看客户端是不是在课间弹出来、上课时是不是安静地收着。规则详见[通知与提醒](../app/notifications.md)。
