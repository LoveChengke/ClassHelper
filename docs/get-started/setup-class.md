# 建班级、排课表

## 创建班级

管理员在“班级管理”填写入学年份、班号、年级等资料；班级名称按年份和班号生成，如“2026级1班”。
设置班主任、学期周数及班级凭据；班主任可暂空，但发布依赖教师归属的内容前需先完成配置。
班级周数默认 20，受全校可配置上限限制，全校默认上限 30、范围 1–60。
保存班级码与密码，教室客户端用它登录；已读和作业状态操作代表全班。

## 录入学生与教师

学生是名单，填写学号和姓名，不创建账号、密码或自动登录名。
学号 1–32 位字母/数字/._-，不能复用；支持管理员表格导入，班主任有名单管理权限时可维护本班。
教师使用工号账号，管理员在教师管理录入或导入。
在班级详情按科目配置任课老师：任课关系只存 Course，决定该科作业/成绩写权限。
班主任不任教某科就不能改该科内容，详见[班级与人员](../app/classes.md)。

## 配置作息与日课表

先在“时间表与课表编辑”维护时间表的上课/课间等时间点，再创建班级日课表并为时间点选择课程。
按星期、周次范围和 1–9 周轮换设置启用规则，也可复制、临时换课或预定某天。
时间表写入需 timetable:manage；日课表写入需 schedule:write 并通过本班班主任/管理员检查。
可以从 ClassIsland 完整 JSON 离线导入作息、日课表、群组与预定，见[导入](../app/imports.md)。

## 校对周次与提醒

管理员在“学期周次”设置开学日、全校上限和逐周日期，班级可以有独立区间。
在周视图和客户端今天时间轴核对当前课程、下一节、上下课时刻。
经典岛普通通知上课暂存、普通叫人保留可点胶囊、紧急消息立即展开；自定义常驻岛先提示铃铛，主动点击查看。
验证应使用独立测试班级，详见[验收](../dev/testing.md)，不要给业务班级发送测试通知。
