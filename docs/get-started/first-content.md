# 发布第一条内容

先完成班级、学生与任课关系配置。页面是否可见及能否发布，由实际功能权限、班级范围和科目关系共同决定。

## 通知与叫人

在“通知发布”选班、填写标题/内容、选择优先级后发布；叫人使用该页叫人入口，选择学生和事由。
通知有低/普通/重要/紧急四档，叫人分普通 HIGH 与紧急 URGENT。
经典岛普通通知上课暂存，普通叫人保留可点击胶囊，紧急消息立即展开；自定义常驻岛先提示铃铛，主动查看。
上课发布紧急通知需服务端二次确认，Web 确认框倒计时结束后才能再次提交。
完整行为见[通知](../app/notifications.md)和[叫人](../app/calls.md)。

## 作业

在“作业发布”选班、科目、所属日期，填写标题与要求；附件为受校验的 http(s) 或站内链接。
作业按所属日期展示，可补录历史日期；科目写权限以本人任课关系为准。
教室客户端可录作业和维护未交名单；本机录入的内容不会再提醒自己。
可选全屏看板与字号/日期等偏好，详见[作业](../app/homeworks.md)。

## 成绩

在“成绩录入”选择班级、考试，单条/批量录入或导入表格。
具备功能权限后，仍只能写自己任教科目；表格导入还要求管理员/本班班主任，按行返回错误和警告，文件上限 8 MB。
班级端个人查询开关开启时可看本班明细与排名，关闭后只看服务端集体分析。
见[成绩](../app/grades.md)和[导入](../app/imports.md)。

## 课件

在“教学事务 → 课件”上传文件，选择本人授课班级并设置“仅保存”或“保存后推送”。
文件先保存到服务端，班级端按可见范围下载；推送离线补领、逐设备回执，客户端不自动运行文件。
单文件上限 512 MB，详见[课件上传与传输](../app/courseware.md)。
