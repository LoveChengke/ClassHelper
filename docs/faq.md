# 常见问题

## 安装与启动

### 双击客户端"点了没反应"

**关窗只是隐藏到托盘，进程还在。** 再双击 EXE 会被单实例锁秒退（看起来像没反应），
安装包也会因为"应用正在运行"装不上。先**从托盘右键退出**。

### 安装包装不上，说应用正在运行

同上。托盘 → 退出 ClassHelper。

## 连接与登录

### 后端明明在跑，`Invoke-WebRequest` 却返回别人的 404

**系统代理拦住了 `127.0.0.1`**。自测请加 `-NoProxy`（`curl.exe` 用 `--noproxy '*'`）。
项目内的 Node 脚本直连，不受影响。

### 客户端连不上服务器

1. 服务器地址要填**局域网 IP**（`http://192.168.1.10:4000`），不要写 `localhost`（那是客户端自己）；
2. 服务器防火墙放行 **4000**；
3. 服务器上如果开了系统代理，内网地址可能被代理接管 —— 浏览器与客户端**不会**自动绕过
   请在系统代理中为内网服务端设置绕过规则；
4. 在服务器本机 `curl.exe --noproxy '*' http://127.0.0.1:4000/healthz` 是不是 200？

### 页面能打开，但接口全 401

令牌过期，或者 `.env` 里的 `JWT_SECRET` 被换过（换过之后所有人的令牌都失效）。重新登录即可。

### 提示「无法连接 GitHub」/ 检查更新查不到

**这是设计内的结果**，不是错误。机房与教室机器常常只有内网，请求会超时；
界面按"暂时查不到更新"呈现。失败结果同样进缓存，不会每点一次都白等一个超时。

### 反向代理后面所有请求都被限流

反向代理没设 `TRUST_PROXY=1`，导致所有请求都被算作代理那一个 IP。

## 功能行为

### 上课时段发的通知学生看不到

**经典模式的设计行为如此。** 上课时段普通通知暂存，下课补弹；自定义常驻模式先提示铃铛。
经典模式紧急消息立即展开，普通叫人保留可点击胶囊；自定义常驻模式先提示铃铛，主动查看。规则见[通知与提醒](app/notifications.md)。

### 老师说发了通知，教室机器上什么都没弹

按顺序排查：

1. 客户端顶栏的实时通道是不是"已连接"？
2. 现在是上课时段吗？（同上，是设计行为）
3. 确认客户端登录的是这条通知对应的班级。
4. 反向代理放行 `/socket.io/` 的 WebSocket 升级了吗？

### 屏幕上出现了第二个灵动岛，点它反应不对

先确认是否有人显式运行了 `verify:desktop:visual` 或 `verify:packaged --visual`；视觉实例由脚本控制，会自行开合。
默认 `verify:desktop` / `verify:packaged` 是后台快速检查，不创建可见岛或托盘。

### 灵动岛上的文字往右跳一下再缩回

那是早期的布局问题（胶囊内容跟着卡片重排），已经修掉了。如果你的版本还有，
说明用的是旧产物 —— 参考[更新与升级](management/upgrade.md)。

### 灵动岛调"左右边距"没反应

**左右边距只在「左 / 右停靠」时生效。** 默认是「顶部居中」，水平锚点就是屏幕中线，
这时调它不会有任何变化 —— 设置页会把那个滑块置灰并写明原因。

### 触摸屏上点不开灵动岛

触摸屏（希沃白板等）会自动走「触摸模式」，正常情况不用手动开。
如果确实点不开，到「设置 → 关于」看一眼诊断信息，并把客户端版本反馈出来。

### 教室机器上刚录的作业又要弹一次？

**本机录入的作业不会上岛**（自己通知自己没意义）。如果弹了，说明这条不是这台机器录的。

### 学生登录不了

**学生没有个人账号。** ClassHelper 班级端统一用**班级码 + 班级密码**登录（见[装 ClassHelper 班级端](get-started/client.md)）。
用学生学号去登录会失败，这是设计。

### 客户端里找不到"修改密码"

**是刻意移除的。** 防止教室机器上误改班级密码后，别的教室机器被锁在门外。
班级密码由管理员在 Web 端「班级管理」维护；教师 / 管理员本人密码在 Web 端顶栏头像菜单里改。

## 开发与运维

### `pnpm db:seed` 报 `Cannot find module '.../@classhelper/shared/dist/index.js'`

`packages/shared` 还没构建（它产出 `dist`，三端与 seed 都依赖）。先 `pnpm build:shared`。

### 根目录跑 `pnpm db:deploy` 说不存在

根 `package.json` 没有这个脚本。正确写法：

```bash
pnpm --filter @classhelper/server db:deploy
```

### 后端改了代码不生效

`tsx src/index.ts` **不热载**。用 `pnpm dev:server`（watch），或重启服务端。
**切换数据库之后必须重启**才会连上新库。

### 上传表格报「服务器内部错误：request entity too large」

表格导入的文件上限是 **8MB**（请求体 12MB），超限应返回 **413 `IMPORT_TOO_LARGE`** 与中文提示。
如果你看到的是英文兜底错误，说明这个异常没被映射 —— 那是 bug，不是你的文件太大。

### 切了 MySQL 之后重启又连回旧库

服务端安装形态里，安装目录的 `.env` **必须是指向 `/etc/classhelper/config.env` 的软链**。
两处不是同一个文件时，一键切换会"看起来成功、重启后又连回旧库"。
Linux 上跑 `sudo classhelper doctor` 有专门一条断言盯着这个软链。

### SQLite 报 `database is locked`

同一个数据库文件只允许一个服务实例。确认没有重复启动；需要并发就换 MySQL。

  记在仓库的 [`AGENTS.md`](https://github.com/LoveChengke/classhelper/blob/master/AGENTS.md) 里；

  附上版本号（Web 端顶栏 / 客户端「设置 → 关于」里都有）和日志。
